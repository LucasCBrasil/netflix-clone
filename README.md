# Netflix Clone

This is a simple web application, that mimics part of the Netflix application (Sign up, Sign in, Home Page - showcasing movies and series - and Profile Page). 

This project was developed only for training purposes, as a way to improve my skills as a frontend developer.

It uses mainly Javascript as the programming language and fetches data regarding netflix movies and series from https://www.themoviedb.org/. It also fetches mocked singing plans from a firebase db.

## How to execute locally

Install all project dependencies using:

npm install

Then, run the project with:

npm run dev

See in which port the application is running and then access it using a browser (by default, the port is 5173).
